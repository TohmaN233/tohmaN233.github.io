fated_poem_pi_front

View repository on GitHub
English

A frontend for the Pi-based "Fated Poem" experience, focused on presenting generated creative output in a usable interface.

This project is only the browser UI, web server, and bridge. Not the game world, characters, saves, memory, or auth.

Installation

./start-web.sh default http://localhost:8787
