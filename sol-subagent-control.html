English

A Sol Advisor fork with a console. Codex-native architect orchestration with Luna and Terra implementation lanes and mandatory fresh Sol review.

This is NOT the original Sol Advisor. Credit to Daniel McAteer / DannyMac180/sol-advisor MIT.

Console Features

Plug tasks/models/thinking in or out, custom tasks, each connection on/off (all start off). Cursor + Grok entries. ChatGPT review uses installed chatgpt-review-agent skill. Luna cannot be the main agent.

Installation

codex plugin marketplace add TohmaN233/sol-subagent-control
sol-advisor@sol-advisor
node install-agents.mjs
