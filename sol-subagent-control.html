English

A Sol Advisor fork with a console. Codex-native architect orchestration with Luna and Terra implementation lanes and mandatory fresh Sol review.

This is NOT the original Sol Advisor. Credit to Daniel McAteer / DannyMac180/sol-advisor MIT. The GitHub About line is inherited from DannyMac180/sol-advisor and is NOT this fork's one-liner.

Console

Console = policy editor only. Calls are made by the control-plane skill / MCP in a new Codex task. Console model + thinking knobs are native-only. Cursor / Grok / ChatGPT web inherit client settings.

Plugin id stays sol-advisor@sol-advisor. Luna cannot be primary. Enabling a provider does not call it. chatgpt-review-agent is not vendored; README assumes it is already installed.

Installation

codex plugin marketplace add TohmaN233/sol-subagent-control
sol-advisor@sol-advisor
node install-agents.mjs
